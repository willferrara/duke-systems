# Duke Companion

> **Status: Experimental / Paused — Active development is focused exclusively on `Duke Launcher`. Please download and use `Duke Launcher` from Releases.**

Headless SteamOS / Bazzite / Linux Tailscale companion daemon (`duke-companion`) for Proton `compatdata` save mapping and BLAKE3 chunk streaming.

Note: `Duke Launcher` operates 100% standalone and gracefully degrades when optional companions are not running.
